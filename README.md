# 🕹️ SURVIVOR

A fast-paced survival game built with 💖 using **Pygame**.  
Dodge, shoot, survive — how long can you last?

---

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/sriharizz/pygame-survivor.git
cd pygame-survivor
2. Install Dependencies
  pip install pygame
3. Run the Game
  python main.py
